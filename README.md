# Cognifyz Technologies – Business Analytics Internship

## Investment Analysis and Participant Preferences

This repository contains the work completed during my Business Analytics Internship with Cognifyz Technologies.

The project focuses on analyzing investment preferences, savings objectives, investment information sources, investment duration, and expected returns using Python and data analysis techniques.

---

## Project Overview

The objective of this project was to analyze a dataset of participants and identify patterns in their investment preferences and expectations.

The analysis covers:

- Dataset structure and data quality
- Gender distribution
- Descriptive statistics
- Investment preferences
- Reasons for investment choices
- Savings objectives
- Sources of investment information
- Investment duration
- Expected investment returns
- Correlation between age, investment duration, and expected returns

## Key Findings

### Participant Distribution

The dataset contains 40 participants:

- Male: 25
- Female: 15

### Investment Preferences

Gold had the highest total score among the investment-related variables, followed by Debentures and Government Bonds.

### Reasons for Investment

Different investment avenues had different dominant reasons:

- Equity → Capital Appreciation
- Mutual Funds → Better Returns
- Bonds → Assured Returns
- Fixed Deposits → Risk Free

### Savings Objectives

The most common savings objectives were:

- Retirement Plan
- Health Care
- Education

### Information Sources

Participants primarily relied on:

- Financial Consultants
- Newspapers and Magazines
- Television
- Internet

### Investment Duration

The most common investment duration was **3–5 years**.

Using representative values for the duration categories, the estimated average investment duration was approximately **2.98 years**.

### Expected Returns

The majority of participants expected returns in the **20%–30%** range.

### Correlation Analysis

The correlation analysis produced the following relationships:

| Variables | Correlation |
|---|---:|
| Age & Investment Duration | 0.05 |
| Age & Expected Returns | -0.09 |
| Investment Duration & Expected Returns | 0.26 |

The results indicate weak linear relationships between the analyzed variables.
